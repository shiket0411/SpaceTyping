# SPACE TYPING — 弾幕タイピング RPG

宇宙を舞台に、**目標の敵に単語を打ち込んで撃墜し、迫る弾幕は迎撃エネルギーで自動的に叩き落とす**タイピングゲーム。
装備・レベル・レアリティを備えたハクスラ要素と、7段階の難易度を持つ。

## 起動

`index.html` をブラウザで開くだけ。ビルド・サーバ・依存パッケージは一切不要
（ES Modules を使っていないため `file://` で直接動作する）。

## 遊び方

| キー | 動作 |
|---|---|
| `A`–`Z` `SPACE` | タイピング（行き先は現在のモードで決まる） |
| `TAB` | 攻撃モード / 迎撃モード の切替 |
| `SHIFT`+`TAB` | 目標を次の敵へ回す |
| `ENTER` | オーバードライブ発動 |
| `ESC` | ポーズ |

### 2つのモード

打鍵の行き先は**モードだけ**で決まる。頭文字の衝突で狙いが逸れることはない。

- **攻撃モード** — 打鍵は目標の敵だけに入る。1打ごとにダメージ、打ち切ると**完撃**で確実に撃破。
  ただし迎撃エネルギーは充填されない。
- **迎撃モード** — 敵とは無関係のワードが出る。打つとエネルギーが貯まるが、その間ダメージは出せない。

### 迎撃エネルギー

迎撃は**モードに関係なく自動**で行われ、1発ごとにエネルギーを消費する。
つまり **容量 = 攻撃モードを続けられる時間**。
撃ち落とした弾の**爆風**に巻き込まれた弾は無償なので、爆風強化は燃費に直結する。

迎撃には**発射間隔**（約3発/秒）があり、一度に押し寄せる弾は撃ち切れない。
エネルギーが尽きると**オーバーロード**となり、容量の35%まで充填し直すまで一切迎撃できず、
その間は被害1.5倍・障壁回復停止。**被弾に無敵時間はない**ので、立て直しが効かない。

### 戦域圧力とレーザー

画面上部の**戦域圧力**は時間とともに上がり、敵を撃破すると下がる。
圧力が高いほど敵は通常弾の代わりに**迎撃できないレーザー**を撃つ。
レーザーは予告線が**自機を追尾**したあと一瞬で着弾する。**必中**で、撃ち落とす手段もない。
対処法は圧力を下げること — つまり**敵を素早く倒し、任務を早く終わらせること**だけ。

これにより「迎撃モードに篭って耐える」が成立しなくなる。実測（s5/ACE を90秒）:

| 立ち回り | 90秒後の圧力 | 撃破 | 到達ウェーブ |
|---|---|---|---|
| 迎撃モードに篭る | 100% | 0 | 1 で停滞 |
| エネルギーで切替 | 89% | 31 | 7 |
| 攻撃モードに固定 | 61% | 32 | 7 |

篭ると撃破が止まって任務が終わらず、高い圧力のままレーザーを浴び続けることになる。

### 難易度の到達点

約69WPM・シード固定16回試行でのクリア率。

| 条件 | クリア率 |
|---|---|
| s1/NOVICE (LV5 Common) | 16/16 |
| s3/PILOT (LV16 Uncommon) | 16/16 |
| s4/ACE (LV24 Rare) | 15/16 |
| s6/VETERAN (LV34 Legendary) | 15/16 |
| s6/VETERAN (LV30 Epic — 装備不足) | 3/16 |
| **s8/NIGHTMARE (LV30 Legendary)** | **5/16** |
| s8/NIGHTMARE (LV70 Legendary) | 10/16 |
| **s8/SINGULARITY (LV30 Legendary)** | **2/16** |
| s8/SINGULARITY (LV70 Legendary) | 7/16 |

レーザーの発生は敵ごとの抽選ではなく**戦域全体の発射間隔**で管理している
（`5 / (0.25 + 圧力² × 3.2 × 難易度係数)` 秒ごとに1発）。敵の数や連射速度で発生量が
乱高下しないようにするため。威力は難易度の被害倍率を掛けない — 難易度差は頻度側で付ける。

圧力は**2乗**で効くので、中盤は散発的だが終盤で牙を剥く。威力も圧力に比例して最大3.2倍。
SINGULARITY の圧力100%では毎秒130前後のダメージとなり、数秒で撃沈する。

### 目標の順番

敵には出現順に番号が振られ、**1番が自動的に目標**になる。撃破すれば自動で次へ進む。
倒しにくい敵を後回しにしたいときは `TAB` で最後尾へ回せる。

### オーバードライブ

正確な打鍵と撃破でODゲージが溜まる。`ENTER` で発動すると
**画面上の敵弾を全消去し、戦域圧力を半減、迎撃エネルギーと障壁を全快**させる。
必要量は**宙域と難易度**で決まる（s1/NOVICE の 60 から s8/SINGULARITY の 565 まで）。

### 設計の核

攻撃し続ければ火力は出るが、エネルギーは減る一方。
**いつ手を止めて充填に戻るか** — この収支の判断が本作の核心。

## 実装メモ

### ローマ字入力（NFA マッチャ）

`js/romaji.js` は、かな1語に対して複数の打ち方を**同時に**受理する非決定性オートマトンとして
実装されている。状態集合を1打鍵ごとに前進させるため、以下がすべて正しく通る:

- `しゅっぱつ` = `shuppatsu` / `syuppatu` / `shixyuppatsu` / `silyuppatu`
- `じゃあく` = `jaaku` / `jyaaku` / `zyaaku` / `jixyaaku`
- `こうしん` = `koushin` / `koushinn`（語尾「ん」の余剰 `n` は吸収する）

逆に IME と同様、`ぎんが` に対する `ginka` や、`てんのう` に対する `tennou`
（= てんおう になる）は正しく **ミス**として弾く。

### バランス設計

- 敵の硬さは HP ではなく**単語の長さ**で表現する。難易度が上がっても敵は極端に固くならず、
  弾幕の密度・速度で難しくなる。
- バランスは現実的な打鍵速度（約69WPM）で全ミッションを5回ずつ走らせて校正した。
  目安は s1/PILOT が無傷、s4/ACE で被弾18回・HP93%、s8/SINGULARITY で被弾44回・HP82%・5回に1回失敗。
- 障壁の回復は打鍵ごとだが、係数を上げすぎると全ダメージを吸収して被弾が無意味になる。
  実測で「被弾44回なのに最低HP100%」という状態が出たため、回復量を絞ってある。
- 弾が当たらない最大の理由は自機の当たり判定が 5px と小さいことだった。難易度ごとに
  **全弾へ誘導バイアス**（0〜0.7 rad/s）を掛け、ばら撒き系のパターンでも自機に寄るようにしている。
  これがないと、迎撃を止めても被弾がほとんど発生しない。
- 想定火力 `expectedAtk` は、実際のドロップ装備を積んだ状態を測定して校正した係数
  （`(10 + ilvl*1.6) * 2.3`）を使う。装備が想定を上回れば単語を打ち切る前に落とせる。
- ボスHPは「何単語で倒せるか」を直接の設計値とし（8〜17語）、装備差で戦闘時間が
  破綻しないよう参照火力に上下限を設けている。

## テストとバランス調整

ブラウザを開かずに、ゲーム本体を Node.js 上でそのまま動かして検証できる。依存パッケージは不要。

```bash
node tools/test.js            # 正当性テスト（約10秒）
node tools/balance.js clear   # 難易度ごとのクリア率
node tools/balance.js style   # 立ち回り3種の比較
node tools/balance.js laser   # 圧力とレーザー致死力の表
```

- **[docs/TESTING.md](docs/TESTING.md)** — テストの走らせ方、出力の読み方、調整の基準値
- **[docs/BALANCE.md](docs/BALANCE.md)** — 調整可能なパラメータの一覧と解説

計測はすべてシード固定なので、同じ引数なら装備の乱数も含めて完全に再現する。
`node tools/balance.js sweep LASER_CURVE=2.5,3.2` のようにパラメータを振って比較でき、
このときソースファイルは書き換えない（メモリ上でのみ差し替える）。

```
js/game.js          ゲームループ / タイピング判定 / 弾幕処理 / 描画

```

設定画面から消去できる。
